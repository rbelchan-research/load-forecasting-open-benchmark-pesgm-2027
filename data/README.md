# Data

Run `python merge_panels.py` once in this folder. It joins the two halves below into
`panel_kva2/`, which is the panel every command in the top-level README points at, and it keeps
the rural-then-urban column order the experiments used, so `--max` samples the same units.

## panel_kva2_rural, panel_kva2_urban

`loads.parquet` is hourly apparent power in kVA for each transformer in the 1,500-unit
stratified sample (800 rural, 700 urban-suburban) across calendar year 2018, built from summed
customer kilowatts through the fitted conversion in `code/build_kva2.py`. `meta.csv` gives each
unit's nameplate rating, homes served, substation, feeder, residential share and fitted
conversion parameters. `weather.parquet` is hourly dry-bulb temperature for each sub-region.

## simulated

Full-year OpenDSS power flow results aggregated to hourly kVA for 554 rural and 600 urban
transformers (1,154 in all). The kW-to-kVA conversion was fitted and validated against these.

## customer_map_4substations.csv

Every load point in the four substations, with its transformer, its kW rating and the SMART-DS
profile file it refers to.

## Not included

`panel_kw/`, the summed customer kilowatts before the kVA conversion, is needed only to refit or
revalidate the conversion (`code/fit_kva.py`, `code/build_kva2.py` and part of
`code/faq_analysis.py`); the Windows build in `code/vps` regenerates it from SMART-DS. The saved
hourly predictions (about 95 MB) are regenerated by `code/run_experiment.py`.

All files here are derived from NREL's SMART-DS and released under CC BY 4.0; see
`../LICENSE-DATA.md` for the attribution.
